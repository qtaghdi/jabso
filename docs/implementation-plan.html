Context — 왜 지금?

이미 증명된 것

Sentry Browser SDK의 envelope를 자체 Next.js endpoint에서 받고, event 및 zlib replay segment를 byte 단위로 해제할 수 있다. 현재 fixture에는 동일 replay의 segment 0–7과 총 106개 rrweb event가 있다.

아직 제품이 아닌 이유

데이터가 로컬 파일에 저장되고 인증·quota·grouping·검색이 없다. Replay 마스킹도 꺼져 있어 현재 코드는 protocol spike로만 취급해야 한다.

제품 정의: Sentry 전체 대체가 아니라 개인 프로젝트를 위한 error inbox + issue grouping + MCP context. DOM Replay와 자체 browser SDK는 후순위다.

기반 완료P0Boundra 자체 오류 기록

재귀 방지 설계: Boundra runtime/adapter 오류는 일반 Jabso ingestion과 failing contract를 통과하지 않는다. 최소 diagnostic sink가 safe shape를 직접 기록하며 nested attempt는 recursion guard로 차단한다.

현재 구현

safe serialization, 길이 제한, process-local recursion guard, 권한이 제한된 NDJSON sink와 테스트가 구현됐다. internal_diagnostics 스키마도 일반 event와 분리되어 있다.

남은 운영 결정

현재 server recorder의 primary는 .jabso-diagnostics/boundra.ndjson다. 외부 배포 전 DB direct sink와 durable fallback을 연결하고 retention을 정한다.

  • 기록: stable code, safe message, field path, contract name, operation, Boundra/Jabso version
  • 금지: original input, token, cookie, authorization header, 임의 환경 변수
  • CI boundary violation은 check-boundaries --format json artifact로 먼저 보존
